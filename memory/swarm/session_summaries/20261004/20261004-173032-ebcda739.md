【风险评估】

1. **紧急风险**：若血压 **≥180/110 mmHg**，尤其 ≥180/120 mmHg，或伴有剧烈头痛、头晕、视物模糊、胸痛、呼吸困难、言语不清、肢体无力、意识改变等，可能提示高血压急症，应**立即就医或拨打急救电话**。
2. **控制不佳的长期风险**：长期血压升高会增加心、脑、肾及血管靶器官损害风险。若已确诊高血压，不建议自行停药、加量或换药。
3. **运动风险**：血压未控制好时，尤其 ≥180/110 mmHg，应避免憋气用力的举重、爆发性运动；可先以散步等温和活动为主，并咨询医生。
4. **特殊人群风险**：肾功能不全者补钾需先咨询医生；老年、虚弱、合并糖尿病、冠心病、心衰、慢性肾病者，血压目标需个体化。
5. **识别风险**：存在“白大衣高血压”（诊室高、家里正常）和“隐匿性高血压”（诊室正常、家里高），家庭血压监测有助于识别。
