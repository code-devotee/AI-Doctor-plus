# Literature Search (文献检索)

用于检索与目标、疾病机制、药物作用和临床前证据相关的文献。

## When to Use

- 评估靶点是否有足够的证据支持
- 需要检索靶点机制、适应症关联和已有药物研究
- 获取研究背景、前期证据和研究缺口

## 底层实现

- 技术: 语义文献检索 + 证据整合
- 目标: 快速获取高质量背景知识

## 调用方式

```bash
/literature-search "EGFR mutation-driven lung cancer mechanism and clinical evidence"
```
