# Skills New

This directory contains the lower-layer skill set for a drug-discovery workflow.

## Layer 1: Skills

- literature-search
- target-analysis
- compound-property-prediction
- toxicology-assessment
- patent-analysis
- experimental-data-extraction
- synthesis-route-planning

## Layer 2: Agents

- target-validation
- molecule-design
- preclinical-assessment

Each skill follows the same convention as the existing .claude/skills structure: a SKILL.md document plus a Python entry script under script/.
